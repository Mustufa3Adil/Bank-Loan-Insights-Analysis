📊 Advanced Bank Loan Data Analysis using Power BI
🔍 Project Overview

This project presents an end-to-end analytical Business Intelligence (BI) solution developed using Microsoft Power BI to analyze bank loan data and uncover actionable insights for better decision-making.

The dashboard suite is designed to move beyond static reports and provide interactive, dynamic, and data-driven insights into loan performance, borrower behavior, and financial health indicators.
It is suitable for banking, finance, risk analytics, and executive reporting use cases.

🎯 Problem Statement

Traditional loan reporting systems lack:

Deep analytical insights

Interactive exploration

Clear visibility into good vs bad loan performance

Real-time KPI monitoring

This limits management’s ability to make informed strategic and risk-based decisions.

✅ Project Objective

The main objective of this project is to:

Build advanced, interactive dashboards

Track key loan performance metrics (KPIs)

Analyze borrower demographics and behavior

Identify good vs bad loan trends

Support data-driven decision-making for banking stakeholders

🛠️ Tools & Technologies Used

Power BI Desktop

DAX (Data Analysis Expressions)

Power Query (ETL)

Data Modeling

Data Visualization & Dashboard Design

📈 Key KPIs Analyzed

Total Loan Applications

Month-to-Date (MTD) Applications

Month-over-Month (MoM) Growth

Total Funded Amount

Total Amount Received

Average Interest Rate

Average Debt-to-Income (DTI) Ratio

Good Loan vs Bad Loan Percentage

📊 Dashboard Structure
1️⃣ Executive Summary Dashboard

Provides a high-level overview of loan performance:

Total & MTD loan applications

Funded vs received amounts

Interest rate and DTI trends

Good vs bad loan distribution

MoM performance tracking

This dashboard is designed for top-level management and executives.

2️⃣ Overview Dashboard

Focuses on trend and distribution analysis:

Loan applications by month

Loan term analysis (36 vs 60 months)

Applications by state

Employment length analysis

Loan purpose distribution

Home ownership impact

This helps identify patterns and borrower behavior.

3️⃣ Detailed Loan Analysis Dashboard

Provides record-level drill-down analysis:

Individual loan details

Purpose, grade, and sub-grade

Funded amount and received amount

Interest rate and installment values

Issue date and loan status

This dashboard supports operational and analytical teams.

📌 Key Insights Generated

Over 86% of loans are classified as Good Loans

Debt Consolidation is the most common loan purpose

Borrowers with longer employment tenure show lower risk

Mortgage and Rent categories dominate home ownership

Clear visibility of charged-off vs fully paid loans
